# 数字小窝 · 静态视觉提案

打开 index.html 对比三种方向，或启动 Vue 开发服务后访问 http://127.0.0.1:5173/designs/index.html。

| 文件 | 方向 | 设计重点 |
| --- | --- | --- |
| a.html | A 暖纸相册 | 米白纸张、衬线字体、实体相册构图、生活故事 |
| b.html | B 星夜来信 | 深蓝与金色、月亮剪影、书信阅读与留白 |
| c.html | C 花园手记 | 植物绿、暖黄色、手绘宠物、轻松亲近 |

## 使用与修改

- 三版都是独立 HTML，通过相对路径引用公共 CSS、JS 和本地 SVG；整个 designs 目录可以复制并离线打开。
- 每个 HTML 的 style 开头包含主题变量：背景、文字、次要文字、强调色、边框、字体。各版布局也在自己的 style 中。
- common.css 管理共用按钮、套餐、弹窗、页脚与响应式基础样式；common.js 管理本地演示交互。
- assets/dog.svg 与 assets/cat.svg 是本次绘制的原创矢量插画，无远程图片或字体依赖。
- 首页“收藏这个方向”保存在浏览器本地，不会发送给服务器；请在对话中告知选择。
- 创建弹窗仅生成本地昵称/照片预览；点亮不写入数据库；无真实订单、付款或照片上传。
- 正式网站和 Java API 未因这些提案调整业务行为，选择视觉方向后再迁移至 Vue 组件。
