# 数字小窝：纪念小屋与安葬档案 PRD

版本：MVP 1.0  
状态：确认执行  
更新：2026-09-08

## 1. 产品结论

本轮把数字小窝从“纪念页面”升级为一套可持续补充的纪念空间，包含四个互相连接的模块：

1. **可布置的纪念小屋**：用“相框、声音、旧物、信箱”四个入口组织内容，不做纯装饰性的 3D 房间。
2. **声音记忆盒**：上传 MP3/WAV，补充标题与故事；公开页可播放。
3. **回忆采访**：使用固定、温和的问题帮助主人开始书写，不使用 AI 虚构宠物经历。
4. **安葬与归处**：记录合规处置方式、日期、城市级地区与纪念文字；默认私密，申请公开后进入人工审核。

核心价值不是“线上墓地交易”，而是帮助家人保存真实记忆、留下有边界的归处记录，并能在纪念日回来看看。

## 2. 用户与场景

- 刚刚经历宠物离世、难以从空白页面开始书写的主人。
- 已经有照片、声音、旧物故事，希望长期整理的家人。
- 收到分享链接，希望点灯、听声音、阅读回忆的亲友。
- 需要处理公开内容、举报和安葬档案申请的审核人员。

## 3. 完整用户流程

```text
创建纪念页
  → 填写基础资料
  → 进入纪念小屋
  → 回忆采访帮助产出文字
  → 上传声音 / 记录旧物
  → 私密保存安葬与归处
  → 选择是否申请公开
      → 否：仅主人可见
      → 是：进入待审核队列
          → 通过：公开页展示城市级信息
          → 退回：显示原因，可修改后重提
  → 发布纪念页
  → 亲友浏览、播放声音、点灯、留言
```

## 4. 功能范围与验收

### 4.1 纪念小屋

- 编辑端提供独立的“小屋布置”页面。
- 小屋包含相框、声音、旧物、信箱四个清晰入口。
- 每个入口显示已有内容数量或状态，并跳转到对应编辑区。
- 公开页只展示确有内容的入口，空模块不占版面。
- 样式基于设计令牌和普通 Vue 组件，后续换配色、圆角、排版不需要改业务逻辑。

### 4.2 声音记忆盒

- 支持 MP3、WAV，单文件不超过 10MB。
- 后端校验 MIME、文件签名、所有权与纪念页归属。
- 主人可添加标题、故事和删除声音；最多 12 条。
- 已公开纪念页中的声音可按范围权限播放，未被引用的媒体进入延迟清理队列。

### 4.3 回忆采访

- 固定六问：初见、昵称、习惯、快乐时刻、教会我的事、最想说的话。
- 每题可独立保存、修改和清空，单题不超过 1000 字。
- 公开页只显示非空答案。
- 产品不替用户生成“真实经历”，防止形成虚假记忆。

### 4.4 旧物故事

- 可记录旧物名称和背后的故事；最多 20 条。
- MVP 不强制上传图片，优先让用户用文字完成记录。
- 公开页以小卡片展示。

### 4.5 安葬与归处

- 可选记录：专业无害化处理、火化、骨灰留存、骨灰安放、其他合规方式。
- 仅收集日期、省/市级地区、场所称呼和纪念文字；不收集经纬度、详细门牌、证件号码。
- 私密保存不需要审核；公开展示必须勾选真实性与合规声明并提交审核。
- 状态为：私密、待审核、已通过、已退回。
- 待审核时不可被公开读取；每次通过或退回必须写理由并进入管理员审计日志。
- 公开页固定显示“家人记录”，并说明平台审核不构成处置资质或合法性的背书。

## 5. 中国大陆内容与合规边界

本功能只提供数字记录与纪念展示，不提供遗体买卖、运输、土葬交易、墓地中介、宠物殡葬资质背书或线下代办。

依据与产品化处理：

- 《中华人民共和国动物防疫法》第五十七条禁止买卖、加工、随意弃置病死动物，并要求相关主体依法进行无害化处理。因此页面不鼓励自行处置，实际处理应遵循当地主管部门或正规机构指引：<https://www.npc.gov.cn/c2/c30834/202101/t20210122_309854.html>
- 《病死畜禽和病害畜禽产品无害化处理管理办法》主要规范畜禽无害化处理，体现公共卫生优先原则；产品文案不得把它扩大解释成对所有家庭宠物情形的一刀切法律结论：<https://www.moj.gov.cn/pub/sfbgw/flfggz/flfggzbmgz/202305/t20230511_478617.html>
- 《网络信息内容生态治理规定》要求平台建立信息发布审核、评论审核、巡查、举报投诉和应急处置制度：<https://www.cac.gov.cn/2019-12/20/c_1578375159509309.htm>
- 《互联网跟帖评论服务管理规定》覆盖文字、图片、音视频等评论形式，因此留言继续实行审核、举报和处置：<https://www.cac.gov.cn/2022-11/16/c_1670253725725039.htm>

正式上线前必须由实际运营主体所在地的法律专业人士复核，并确认当地动物卫生、城市管理、民政、市场监管与数据处理要求。

## 6. 审核规则

### 自动拦截

- 精确地址、经纬度、证件号码、联系方式等敏感信息。
- 宣称出售、收购、运输宠物遗体或代办墓地的交易性内容。
- 违法、暴力、仇恨、骚扰、诈骗引流等现有内容规范禁止的信息。

### 人工审核

- 记录方式与描述是否一致。
- 场所称呼是否包含详细地址或商业导流。
- 纪念文字是否泄露个人隐私或包含违规内容。
- 审核只判断“是否适合公开展示”，不判断线下机构资质真实性。

## 7. 数据与权限

- 所有新增表均通过 `memorial_id` 级联绑定纪念页。
- 主人端每次读写都同时校验当前用户与纪念页所有权。
- 公开接口先校验纪念页发布状态与访问范围，再返回内容。
- 安葬档案仅在 `APPROVED` 时进入公开响应。
- 音频读取沿用媒体权限模型，支持公开、链接、口令和主人访问。
- 管理员审核要求运营/审核角色，并记录操作者、原因、时间和目标。

## 8. 商业模式

MVP 不对点灯、线上祭扫或安葬档案审核收费，避免把哀伤互动做成付费压力。

- 免费：1 个小窝、基础图文、回忆采访、3 条声音、5 条旧物、私密安葬档案。
- 守护版（计划）：更大媒体容量、完整声音盒、纪念日提醒、长期托管。
- 珍藏版（计划）：家庭协作、资料导出、高清纪念册、托管年限扩展。
- 人工服务（现有）：只做数字内容整理和页面制作，不承接线下遗体处置。

付费能力继续保持“真实支付未开放”的产品状态；上线前需完成主体、商户、退款和客服流程。

## 9. 指标与上线门槛

关键指标：

- 创建后 7 日内完成至少两个小屋模块的比例。
- 回忆采访的开始率与完成三题以上比例。
- 声音上传成功率、播放成功率。
- 安葬档案申请公开率、审核通过率、平均审核时长。
- 公开页二次访问率、点灯率、举报率。

上线门槛：

- 后端权限隔离、媒体签名、公开过滤、审核审计测试通过。
- 前端类型检查、单元测试、生产构建通过。
- 桌面端与移动端完成实际浏览器验收。
- 法务复核、审核人员与投诉渠道准备完成后，才开放安葬档案公开申请。

## 10. 本轮暂不做

- 真实宠物墓地地图、导航和精确定位。
- 线下服务商入驻、资质认证、交易、遗体运输与代办。
- AI 克隆声音、数字分身、宠物“回话”。
- 付费虚拟香烛、贡品排行或公开攀比。
- 未经人工审核的安葬信息自动公开。
