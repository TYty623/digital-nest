# B「星夜来信」正式站设计与验收

## 产品视角与设计约定

用户是想保存宠物陪伴记忆的家人，不是来操作数据仪表盘的人。首屏先说明“给谁、保存什么”，再给出创建入口；纪念页以昵称、照片、陪伴日期和信件为第一阅读对象。高频工作是编辑文字和整理媒体，低频但高风险操作是发布、改变访问权限、删除与付费。保留 Java + Vue，不引入新的建站平台。

- 视觉基准：用户确认的 `web/public/designs/b.html`；深蓝 `#141f2c`、暖金 `#d8be88`、米白文字、宋体标题。
- 首页留白宽松，正式编辑器采用中等信息密度。桌面为目录 / 单列编辑 / 预览；手机切换编辑和预览，不把两栏挤在一起。
- 主操作是真实的创建、保存、分享；演示故事明确标注。禁止虚构用户数、倒计时促销、付费看纪念、自动播放音视频。
- 暖阳和花园是内容页可选主题，不因站点改版强制改写用户已有主题；新小窝默认星夜。
- 视觉验收包含 390px / 1440px、错误状态、键盘导航、表单与对比度检查。功能验收不以截图代替。

## 参考模式与取舍

除了用户确认的 B 提案，仅借鉴邻近产品的交互原则，不复制其品牌界面：

1. [Apple Photos 回忆](https://support.apple.com/en-gb/guide/iphone/iphd4f70e68f/ios)：围绕人物、宠物与事件组织媒体；本项目保留宠物为叙事中心，不做自动剪辑与音乐播放。
2. [Notion 侧边导航](https://www.notion.com/help/navigate-with-the-sidebar)：让长内容有明确入口；本项目对应封面、日常、时间线、相册、信件与隐私目录。
3. [Day One 导出](https://dayoneapp.com/guides/tips-and-tutorials/exporting-entries/)：私人记录应能带走；本项目保留 ZIP 原始媒体、结构化 JSON 和可读 Markdown 导出。

## 本次补强内容

- 手机版菜单可访问登录、账户及管理台；退出失败显示明确提示。
- 创建过程在 IndexedDB 暂存文字与封面，24 小时有效；浏览器不支持时明确告知。此为同一浏览器下的本机草稿，不跨设备同步；登录提交成功后清理。
- 新小窝默认星夜；校验图片类型 / 5MB 大小与陪伴日期顺序，释放被替换的图片预览 URL。
- 自动保存记录提交快照；请求期间的新输入会继续保存，不把未提交文字标记为已保存。重复保存被阻止，发布失败仍保留服务器最新版本号。
- 相册使用可响应的上传队列、逐个上传、真实进度、超时与取消处理；失败项可单独重试或移除。封面在相册中仅计数一次。
- 预览能展开相册、短视频、时间线与信件；手机标签支持方向键。已发布页面“保存即更新”的实际行为明确说明。
- 公开相册支持大图、前后翻页、Esc 关闭；不同路径重新挂载页面，避免前一个小窝残留。
- 未登录 API 返回明确 401 JSON；用户资料初始化合并并发请求，网络错误可重试。
- 本地 H2 改用文件数据库，上传和数据库都保存在 `server/data`；会话表初始化可重复执行。

## 使用与上线边界

运行 `powershell -ExecutionPolicy Bypass -File deploy/start-local.ps1`，浏览器打开 `http://127.0.0.1:5173`；脚本仅监听本机，不结束占用端口的未知程序。日志在 `deploy/data/logs`。原内存模式在本次启动前已经停止，内存中的历史数据无法追溯；本次起新增内容落盘。备份前先正常停止 Java，再复制完整 `server/data`，不要只备份图片。

本地模拟支付不会真实扣款。生产仍需完成：商户开户与支付回调验签、邮件验证/找回密码服务、域名 HTTPS、备案与经营主体文案、正式数据库与备份恢复演练、对象存储及审核服务。不要把本地可运行等同于已经可商业上线。
