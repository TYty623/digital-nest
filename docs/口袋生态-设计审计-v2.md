# 口袋生态 v2 设计契约与审计

用户要在有真实材质感的场景里安放记忆、布置与陪伴。第一眼必须看到场景本身，同时能够更换空间和开始放置记忆物件。沿用深蓝暖金；参考用户截图中的场景占据首屏、浮动编辑面板、物件配置与成品预览三种模式。

## 初审 HOLD

1. 写实横幅与矢量卡通场景分成上下两套产品；移除主路径中的重复展示，改为一块可操作场景。
2. 主要动作埋在第二屏；首屏放入场景切换、记忆物件、光线、预览和导出。
3. 云宠互动只有短句，没有纪念对象；增加名称、真实日期、便笺、持久化摆放物件及纪念卡导出。
4. 等高大卡片留白与信息无关；改成主画布＋窄工具面板，手机画布先于工具。
5. 保存数据没有导出；增加包含便笺和布局的 JSON 下载及场景 PNG 纪念卡。

## 实现边界

用户追加要求允许像素风，强调暖心纪念及去 AI 风格。最终主体验改为代码绘制的原创像素场景，不再加载生成式主图。鱼游动、投喂和小猫动作由 Canvas 渲染；记忆物件可以点击或键盘放置、收回，日期便笺真实保存，PNG 卡片导出当前像素场景及最新便笺，JSON 导出全部资料。新增 v2 存储不覆盖旧版数据；原插画模式保留为独立轻量入口。

新增 `web/src/components/PixelHabitat.vue` 负责画面与动态；`HabitatStudioView.vue` 负责纪念资料、物件与导出。没有 AI 对话、排行榜或饥饿惩罚。

## v3：从玩具转为纪念对象的私有角落

审计复核发现“仅本地保存、与纪念资料脱节”会把这个模块变成小游戏，因此增加了最小且可删除的账户存储模型：`memorial_habitat_spaces`、`memorial_habitat_items`、`memorial_habitat_notes`。从某一个纪念小屋进入时，布景、光线、物件和便笺只属于该纪念对象，随纪念对象删除而级联删除；没有公开页、推荐流或互动计数。

便笺可从“TA 的一天”、旧物故事和生命指纹带入，并在便笺上保留来源标签；用户仍可改写或只写手动便笺。没有把像素猫、鱼或场景称为逝者的替身，页面明确是“为记忆留的一处风景”。未登录或从导航直接打开时，保留本浏览器私密体验与 JSON 备份，不伪装成云端已保存。

## 验收记录

生产构建、TypeScript、ESLint、新增端到端测试通过。测试覆盖键盘放置物件、便笺保存及刷新恢复、猫咪互动、PNG 下载、390px 无横向溢出。已实际查看桌面与手机截图；进一步压缩主画布宽度，移除主路径图片与卡通混用，补齐像素家具细节，并修复跳转链接未聚焦时的显示位置。

验收：桌面 1440 与手机 390；场景切换、物件放置与撤销、便笺保存刷新、两种导出、减少动态及图片加载失败；已新增账户空间、来源便笺、删除接口与级联删除测试。
