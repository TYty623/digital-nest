# Taste Skill 网站审查与改进

更新时间：2026-09-08

审查依据：[Leonxlnx/taste-skill](https://github.com/Leonxlnx/taste-skill) 中的 `design-taste-frontend` 与 `redesign-existing-projects`。本次采用保留式改版，不改变 Vue + Java 技术栈、页面路由、信息架构、表单字段和业务功能。

## 1. 设计读法

这是面向中国大陆宠物家属的纪念产品。视觉需要亲密、可信、克制，并保持编辑式的深夜纪念语言。深海蓝与柔金是现有品牌识别；中文宋体用于纪念信和标题，是由纪念、书信与档案语境支持的选择，不是泛用的“高级感”装饰。

设计参数：

- `DESIGN_VARIANCE: 6`：保留清晰结构，用少量非对称构图避免模板化。
- `MOTION_INTENSITY: 4`：只保留有叙事、反馈或状态意义的低频动画。
- `VISUAL_DENSITY: 4`：营销页留白充足，编辑器与管理页维持日常工具密度。

## 2. 审查发现

| 优先级 | 问题 | 影响 | 处理 |
|---|---|---|---|
| P0 | 首屏有眉题、三行标题、两行说明、两个按钮和按钮下说明，共五层文字 | 主张不够集中，首屏更像模板 | 标题收成两行，说明收成一句，信任信息移至首屏下方 |
| P0 | 首屏使用代码绘制的星空动物插画 | 画面像占位稿，缺少真实生活质感 | 换成项目专属的宠物生活痕迹摄影资产 |
| P1 | 首页连续使用英文眉题及 `01/02/03` 编号 | 形成明显的 AI 模板节奏 | 只保留两个必要眉题，去除装饰性章节编号 |
| P1 | 两组内容采用三等分布局 | 功能之间没有主次，页面节奏重复 | 核心体验改为 1+2 非对称结构，承诺区使用轻微比例差 |
| P1 | 主导航只有文字变色，按钮没有明确按压反馈 | 当前页识别和操作触感偏弱 | 增加导航细线状态和按钮按压反馈 |
| P1 | 首页缺少基础描述与社交分享元数据 | 搜索摘要和分享回退不完整 | 增加 description、主题色、Open Graph 与 Twitter 卡片 |
| P1 | 原始图片约 4.3MB | 影响首屏最大内容绘制 | 转为适配展示尺寸的 WebP，总计约 220KB，并声明固有尺寸 |
| P2 | 日期范围和空值大量使用长破折号 | 容易形成机械化排版习惯 | 日期改用普通连字符，空值改为“未填写” |

## 3. 已完成修改

- 新增首屏生活痕迹照片和“小麦在窗边”演示照片，均为本项目生成并本地托管的 WebP。
- 首页首屏保持一个主张、一句解释和两个不同意图的入口。
- 原功能编号条改为隐私、导出和免费查看的信任信息条。
- 纪念信以真实演示照片和正文形成杂志式双栏，而不是通用卡片。
- 核心体验区采用不对称 1+2 网格；移动端明确回落为单列。
- 导航增加当前页面状态，按钮和记忆问题增加按压反馈。
- 保留原有滚动渐显、场景切换与点亮反馈，并继续支持减少动态效果偏好。

## 4. 下一阶段建议

以下建议需要先验证用户意愿，不在本次视觉改版中擅自加入：

1. **纪念日回看**：由馆主主动选择日期和是否提醒，只重现已经写过的内容。
2. **年度记忆册**：把真实照片、一天片段和生命指纹排成可下载或印刷的纪念册，形成明确付费价值。
3. **共同补记邀请**：馆主向指定亲友发出一次性问题，回答先进入私密待确认区，避免公开社区变重。
4. **主题策展**：纪念星河按“最爱的窗边”“等门的声音”等生活主题展示公开片段，不做热榜。

建议优先观察首屏到创建页的进入率、记忆采样器使用率、回访后新增真实内容的完成率，以及首屏图片的 LCP。不要用单纯停留时长判断纪念产品是否成功。

## 6. 验证结果

- Vue 单元测试：10 项通过。
- Playwright 全栈 E2E：9 项通过，覆盖创建、草稿恢复、上传重试、发布、分享、移动端布局、后台审核与支付回退。
- TypeScript 构建与 ESLint：通过。
- Lighthouse 生产构建预览：Performance 85、Accessibility 100、Best Practices 96、SEO 100；FCP 1.2s、LCP 2.2s、CLS 0。
- Lighthouse 的剩余控制台错误来自独立 Vite Preview 未代理 `/api`；正式同域部署配置会将 `/api` 转发到 Java 服务。浏览器前进后退缓存项目被 Lighthouse 标记为内部不可操作原因。
