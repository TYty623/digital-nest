# 数字小窝全面审查与 UI 升级报告

审查日期：2026-09-09

## 结论

当前版本可以作为本地演示和下一阶段产品验证版本交付。纪念空间是主路径，记忆角落和轻量互动是可选附属体验；没有把哀伤、排行、打卡或虚构的 AI 陪伴做成留存机制。

本轮不只输出报告，已经完成了导航、异常处理、可维护性和视觉验收脚本的升级。前端与 Java 服务都保持运行，完整测试已通过。

## 产品与功能审查

### 已确认成立的核心体验

1. 建立纪念空间后，用户可以整理生命档案、日常瞬间、旧物、照片、视频、录音、时间线和地图。
2. 仪式中心是有开始、回看、动作、收束的私密流程，支持点灯、种花、写一句话、打开信件与收进时间胶囊。
3. 日历、时间胶囊、年度纪念册和基础导出均按“由用户主动决定何时回看”的节奏设计。
4. 亲友和纪念星河是授权后的附属协作和弱社区，没有粉丝数、热榜或连续打卡。
5. 记忆角落可从具体纪念空间进入，物件和便笺按该空间私密保存；直接打开时才是本机临时模式。
6. 数字生命只以授权资料、来源追溯、模拟问答和功能开关为边界。声音与形象仍是未开放接口，不宣称复活或意识延续。

### 信息架构判断

主路径现在是：建立或进入“我的纪念” -> 收集生活细节 -> 选择纪念动作或回看 -> 在需要时进入记忆角落、年度册或纪念星河。

这是“渐进披露”的交互结构：一开始只要求用户做一件低压力的小事，更多工具在需要时才出现。对纪念产品而言，它比把所有功能堆在首页更合适，也能降低用户第一次面对材料时的负担。

## UI 升级报告

### 设计契约

| 维度 | 当前取值 | 判断 |
| --- | --- | --- |
| 视觉方向 | 深蓝底色、暖金文字和边界、真实生活照片、低饱和图像 | 保持安静与温度，不走哀伤营销或游戏化路线 |
| 信息密度 | 中等 | 首页负责建立理解，编辑器负责集中工作，纪念页负责阅读与回看 |
| 动效强度 | 低到中等 | 只用于区块进入、灯光、物件安放和状态反馈 |
| 无障碍策略 | 键盘焦点、跳至正文、移动菜单、`prefers-reduced-motion` | 减少动态偏好下动画静止，声音默认不自动播放 |
| 响应式 | 390px、768px、1440px 验证 | 移动端折叠为单列，已验证无横向溢出 |

### 页面验收结果

| 页面 | 通过点 | 本轮调整或确认 |
| --- | --- | --- |
| 首页 | 首屏有明确承诺和两条行动路径；随后有演示故事、记忆提示、弱社区说明、隐私承诺和 FAQ | 修正视觉截图对屏外进入动画的误判，确认长页内容按阅读进度出现 |
| 建立与编辑 | 表单、媒体、时间线、亲友留言和实时预览分层清楚 | 桌面三栏工作台与手机单列均通过无横向溢出检查 |
| 公开纪念页 | 优先显示生活细节、仪式入口、媒体、时间线和留言 | 不把离开日期做成唯一主视觉，不强迫分享 |
| 记忆角落 | 像素场景、布景、记忆便笺和导出卡片形成一个轻量场景编辑器 | 修复生产构建错误，保留暂停动画与私密提示 |
| 纪念星河 | 主题浏览、编辑精选、克制问候和互动关闭 | 不显示粉丝数和热榜，符合弱社区定位 |

### 审查中主动保留的克制

- 没有增加满屏粒子、漂浮花瓣、闪烁星星或自动播放音频。
- 没有把数字生命做成“宠物真的回来”的拟人化承诺。
- 没有为高级会员阻断基础纪念、数据导出和删除入口。
- 没有为了视觉“高级”而改动既有 URL 或纪念资料表单字段。

## 代码与安全审查

### 已验证的保护措施

- Spring Security 对需要登录的接口默认要求认证，管理员接口要求相应角色。
- 会话 Cookie 为 HttpOnly、SameSite=Lax，生产配置默认要求 Secure Cookie；修改请求使用 CSRF Token。
- 纪念空间、记忆角落、媒体和导出数据由服务端按所有者或访问权限验证，不依赖前端隐藏按钮。
- 数据导出下载令牌只保存哈希并有过期和消费逻辑。
- 公共留言、点灯、举报和后台审核已有专门流程与限流覆盖。
- 本轮新增未知异常兜底，并以单元测试验证异常原文不会被返回到浏览器。

### 仍属于正式上线前条件，不应忽略

1. 使用受管 PostgreSQL、对象存储、TLS 和备份恢复演练替换本地运行环境。
2. 对上传的图片、音频和视频接入恶意文件扫描、异步转码和生产级内容审核。
3. 短信、邮件或系统通知提醒需要真实服务商、退订机制和用户确认流程后再开启。
4. 数字生命的真实模型、语音和形象能力必须在资料授权、未成年人保护、删除链路、生成式 AI 合规与人工审核都完成后才可开放。
5. 在 CI 中固定使用官方 npm 审计源或等效的软件成分分析服务，防止镜像站不提供漏洞接口时失去可见性。
