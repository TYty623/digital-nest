- B「星夜来信」落地正式 Vue 网站；主色和排版集中配置，已有暖阳与花园纪念页仍独立保留主题，详见 [设计与验收](./B-星夜来信-设计与验收.md)；
- 本机创建草稿在 IndexedDB 暂存照片与文字 24 小时；自动保存快照防覆盖、上传异常恢复、相册大图、手机菜单和标签键盘操作；
- 本地 H2 文件持久化与可重复初始化的会话表；Java 重启前后测试账户订单记录一致；并发媒体添加受事务行锁保护；

- Vue 3 + TypeScript 前端与 Java/Spring Boot 模块化单体后端；同域 Nginx 路由配置；
- “生命纪念馆”核心体验：可增删改并按时刻浏览的“TA 的一天”、十项生命指纹、每日稳定重现一条真实记忆的“今天想起”，以及只收录主动公开纪念页摘要的“纪念星河”弱社区；完整设计与边界见 [核心体验 PRD](./生命纪念馆核心体验-PRD.md)；
- 情绪设计与温和回访层：全站滚动渐显与低频星夜环境动效、首页四类“记忆采样器”、我的小窝每日真实记忆回访卡、纪念小屋六项记忆轨迹，以及公开页场景切换和点亮反馈；系统尊重减少动态效果设置，不使用签到、排行或焦虑提醒；
- 创建流程修复未来日期前后端校验不一致、未保存却提示成功的问题；保存成功后直接进入纪念小屋继续布置；
- 全局键盘焦点样式与“跳到主要内容”跳转链接；390／768／1440 宽度下的首页、创建页和公开纪念样板无横向溢出；
- 邮箱账户、会话 Cookie、CSRF、登录限流、资源级权限与管理员审计；
- 创建向导、草稿自动保存与离开未保存内容提醒、可选陪伴日期、关于 TA 的性格与日常、相册、可关联相册图片并手动排序的时间线、纪念信、三套主题、编辑器和分享卡片；编辑器在桌面端为模块导航／编辑区／实时预览三栏，在移动端切换“编辑内容／实时预览”标签；
- 私密／链接／口令／公开四种访问范围。已发布页面改为“仅自己可见”时会立即下线，恢复分享时保留原链接；
- 图片及短视频大小、MIME 类型和文件签名校验；编辑器以浏览器真实上传进度逐文件显示媒体状态，失败项可单独重试；短视频仅限 MP4／WebM、30MB，支持受控 byte-range 播放且不自动播放；私有媒资受控读取；移除相册媒体立即撤销访问，24 小时后物理清理；
- 留言、点亮、举报、待审核与主人/管理员处置；运营角色可巡查公开纪念页、填写原因后立即下线并保留审计记录；匿名访问按“纪念页 + HMAC-SHA-256 指纹 + 当日”去重，并在管理台展示当日/近 7 日访问、新建/发布小窝、主人主动分享、受控媒体用量和近 30 日已支付订单；
- 服务端锁价订单、幂等本地模拟支付、运营角色可填写原因撤销模拟订单并同步撤销权益、套餐权益、人工定制工单；编辑器先读取服务端有效容量并在选择媒体前提示剩余图片/短视频名额，写入时仍由后端再次校验；真实支付默认关闭；
- 数据导出、延迟删除与撤销、隐私/条款/内容规范/退款说明页；
- 生产启动门禁：拒绝示例/过短数据库密码、非 Secure Cookie、弱访客指纹密钥与模拟支付；
- 动态分享元数据对用户文本 HTML 转义；公开页 Vue 模板不使用原始 HTML 注入；
- Docker Compose、运行手册以及数据库和上传媒体的成对备份/恢复脚本。

## 仍需真实外部条件才能称为正式上线

1. 已备案域名、TLS 终止反向代理和服务器访问控制；
2. 实际运营主体、隐私/用户/退款条款的法务复核及客服渠道；
3. 微信或其他支付商户号、服务端验签密钥、回调地址和真实退款流程；
4. 对象存储/CDN 账号与迁移演练（当前 Compose 使用受控本地上传卷，适合单机部署）；
5. 独立备份存储、实际恢复演练、监控告警和发布回滚记录；
6. 10 名种子用户任务测试与 P0/P1 缺陷清零记录。

这些事项依赖账户、域名或外部组织授权，不能在代码仓库中替用户完成，也不应通过模拟配置绕过。
